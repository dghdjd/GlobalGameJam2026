# Vancouver Global Game Jam 2026
# Neil: A Big Halloween 🎃

A short narrative-driven game developed using Unity during a game jam, focusing on player–NPC interactions, dialogue choices, and atmosphere through audio and UI feedback.

👉 **Play the game here:**  
https://yutzune.itch.io/neil-a-big-halloween

---

## My Role & Contributions

I was responsible for the **core interaction and dialogue experience** of the game, including:

### 1. Player–NPC Interaction System
- Implemented the interaction mechanism that allows the player to detect and interact with nearby NPCs.
- Handled interaction states to ensure smooth transitions between exploration and dialogue.

### 2. Dialogue System Integration (Yarn Spinner)
- Integrated **Yarn Spinner** to connect dialogue scripts with in-game NPCs.
- Implemented logic to:
  - Trigger the correct dialogue node based on the NPC being interacted with.
  - Display the corresponding **character portrait** when dialogue starts.
- Ensured dialogue UI updates correctly when switching between different NPCs.

### 3. Audio & Feedback Integration
- Implemented and connected game audio to enhance player feedback and immersion, including:
  - Footstep sound effects during player movement.
  - Sound effects for dialogue lines.
  - UI sound effects for:
    - Dialogue box opening
    - Option hover
    - Option click
